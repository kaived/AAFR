# Tools

This folder contains helper tools for experiments and analysis.

## Subfolders

| Path | Purpose |
| --- | --- |
| `eval/` | parse telemetry and generate metrics |
| `netem-profiles/` | future network emulation scripts/profiles |

## What To Add Here

- telemetry parsers
- metric aggregation scripts
- plotting scripts
- reproducibility manifest tools
- network emulation helpers

## Rule

Tools should be scriptable from the command line so experiments can be repeated.
