# Search icon

`google-g.png` is Google's G search-provider mark, downloaded from:
https://www.gstatic.com/images/branding/googleg/1x/googleg_standard_color_128dp.png

It is bundled as a Qt resource and identifies Google search in the two search
fields only when the configured search endpoint uses `google.com` or
`www.google.com`. Other providers use AAFR's neutral search icon. No remote
image request occurs at browser startup. The mark does not identify AAFR's
rendering engine or imply Google owns the application.
